## 📊 반도체 사이클 용어 (가장 중요!)

### Q싸이클 (Query / 공급부족 사이클)
**정의**: 수요 > 공급인 시기 (메모리가 부족한 상태)

```
특징:
• 메모리 가격: 매우 높음 ⬆️⬆️
• 이윤(GPM): 80~90% (최고)
• 지속성: 좋음 (기초 수요가 있음)
• 판단: "황금기" 🌟

예시: 
AI 붐으로 GPU 수요 증가
→ HBM 메모리 부족
→ 공급사들 대박
```

### P싸이클 (Pricing / 가격 프리미엄)
**정의**: 공급 부족은 없지만 가격이 일시적으로 높은 시기

```
특징:
• 메모리 가격: 높음 ⬆️
• 이윤(GPM): 60~70% (중간)
• 지속성: 약함 (언제든 가격 하락)
• 판단: "위험 신호" ⚠️

예시:
시장에 물량은 많은데
심리적으로 가격이 높음
→ 나중에 급락 가능성
```

### 싸이클 (Cycle)
**정의**: 반도체 가격의 주기적 흐름

```
일반적 싸이클:
상승기 → 고점(P싸이클) → 하락기 → 저점 → 상승기
 ↑                                          ↑
 └─────────── 한 사이클 ────────────────┘

Q싸이클: 상승기 중 "수요 > 공급" 구간
P싸이클: 고점 근처 (가격 높지만 공급 충분)
```

## 💰 성과 지표

### GPM (Gross Profit Margin / 총이익률)
**정의**: 매출에서 원가를 뺀 이익의 비율

```
계산식: (매출 - 원가) / 매출 × 100%

예시:
반도체 가격: 100만 원
원가: 20만 원
GPM = (100 - 20) / 100 × 100% = 80%

의미:
• GPM 80~90%: 황금기 (Q싸이클)
• GPM 40~50%: 어려운 시기 (P싸이클)
• GPM 높을수록 좋음 = 수익성 높음
```

### PER (Price-to-Earnings Ratio / 주가수익비율)
**정의**: 주가 ÷ 주당순이익 (기업이 비싼지 싼지 판단)

```
해석:
• PER 10배: 싼 가격
• PER 20배: 평균
• PER 30배 이상: 비싼 가격

예시:
삼성 주가 70,000원
주당순이익 7,000원
PER = 70,000 ÷ 7,000 = 10배 (싼 가격)
```

### EPS (Earnings Per Share / 주당순이익)
**정의**: 회사의 순이익을 발행 주식 수로 나눈 값

```
높을수록 좋음
→ 1주당 얼마나 벌었는가
→ 배당금, 주가 상승에 영향
```

## 🏭 반도체/기술 용어

### HBM (High Bandwidth Memory)
**정의**: 매우 빠른 메모리

```
특징:
• 일반 메모리: 옆으로 길다 (느림)
• HBM: 높이 쌓아올림 (빠름)

용도:
• AI/GPU 칩의 필수 부품
• NVIDIA, Google, Tesla 등 필요
• 수요 증가 → 가격 상승 → 수익 증가

현재 상황:
HBM 수요 증가 = Q싸이클 가능성
```

### NAND/DRAM
**정의**: 메모리의 두 가지 종류

```
DRAM:
• 용도: 주기억장치 (임시 저장)
• 가격: 상대적으로 저렴
• 용량: 적음
• 삽성, 하나마이크론, SK하이닉스 생산

NAND:
• 용도: SSD, USB, 스마트폰 저장공간
• 가격: 비쌈
• 용량: 큼
• 더 수익성 높음
```

### SCA (Sustainable Competitive Advantage / 지속가능한 경쟁우위)
**정의**: 경쟁사가 쉽게 따라올 수 없는 강점

```
반도체 예:
• 삼성: 3D NAND 기술
• SK하이닉스: HBM 기술
• TSMC: 5nm 공정

의미:
SCA가 있으면
└─ 장기 수익 보장 = 투자 매력도 ⬆️⬆️
```

### CAPEX (Capital Expenditure / 자본지출)
**정의**: 공장, 장비 등 구매에 드는 비용

```
예시:
반도체 공장 신축: 10조원
= CAPEX 증가

영향:
• CAPEX 높으면 → 단기 이익 ⬇️
• CAPEX 높으면 → 미래 생산량 ⬆️
• 장기관 단기를 봐야할지 결정

주의:
CAPEX 크면 실제 수익보다 적게 보일 수 있음
```

## 💼 투자 기본 용어

### 레버리지 (Leverage)
**정의**: 차입금으로 투자 규모를 확대하는 것

```
예시:
내 자금: 100만 원
차입금: 10만 원
총 투자: 110만 원 = 10% 레버리지

장점:
• 수익률 2배 가능
• 예: 100만 수익 × 1.1 = 110만 수익

단점:
• 손실도 2배
• 예: -10% 손실이 나면 전체 포트 -11%

주의:
반드시 손절 기준을 명확히 할 것!
```

### 매도 / 익시트 (Exit)
**정의**: 보유한 주식을 파는 것

```
매도의 어려움:
• 언제 팔아야 하는가? (불명확)
• 더 오를 것 같음 (심리)
• 손실을 확정하고 싶지 않음

선진짱의 조언:
"싸이클의 끝을 보려면 
수익의 20~30%는 손실 각오 필요"
→ 완벽한 타이밍은 불가능
→ 기준을 정해놓고 실행
```

### 손절 (Stop Loss)
**정의**: 손실이 일정 수준에 도달하면 자동으로 파는 것

```
예시:
진입가: 100,000원
손절가: 95,000원 (-5%)

의미:
최대 손실을 제한해서
포트폴리오 전체 손실을 최소화
```

### 목표가 (Target Price)
**정의**: 주가가 도달했으면 하는 목표 가격

```
예시:
진입가: 100,000원
목표가 1차: 110,000원 (부분 익절 30%)
목표가 2차: 120,000원 (부분 익절 40%)
목표가 3차: 130,000원 (나머지 익절 30%)

의미:
단계별 익절로 수익을 확정
너무 욕심내지 않기
```

## 🔄 비즈니스 모델

### B2C (Business to Consumer)
**정의**: 기업 → 소비자 거래

```
예시:
• 삼성 스마트폰 판매
• 애플 아이폰 판매
• 마트 물품 판매

특징:
• 소비자 심리가 중요
• 광고, 브랜드 가치 중요
```

### B2B (Business to Business)
**정의**: 기업 → 기업 거래

```
예시:
• 반도체 납품 (TSMC → Apple)
• 메모리 공급 (삼성 → 노트북 회사)

특징:
• 계약 기반
• 가격 변동이 예측하기 어려움
• 대량 거래

블로그의 의미:
"메모리는 B2B이라서..."
→ 개별 소비자와의 거래가 아니라
→ 기업 간 거래라 가격 변동이 예측 어려움
```

## 📈 당신의 투자 프레임워크와의 연결

### WHAT 단계에서 사용
```
용어: Q싸이클, SCA, HBM
의미: 좋은 펀더멘탈을 가진 종목 찾기
└─ HBM 수요 증가 (Q싸이클 가능성)
└─ 반도체 회사 SCA 보유
```

### WHEN 단계에서 사용
```
용어: P싸이클 vs Q싸이클, 신고가, 매물대
의미: 좋은 진입 타이밍 찾기
└─ P싸이클 피하기 (위험)
└─ Q싸이클 신호 기다리기 (신고가, 매물대 돌파)
```

### HOW 단계에서 사용
```
용어: 레버리지, 손절, 목표가, 비중
의미: 리스크 관리
└─ 레버리지 몇 %?
└─ 손절 기준은?
└─ 목표가 설정은?
└─ 포트 비중은?
```
