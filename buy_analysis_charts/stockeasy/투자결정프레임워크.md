# 투자 결정 프레임워크 (2단계)

> 변동성 시장에서 **무엇을 + 언제를** 결정하는 체계적 접근

## 📌 핵심 원리

좋은 종목(가치) ≠ 좋은 진입점(추세)
**둘 다 만족해야 매매 신호 ✅**

---

## 🤔 왜 개별 주식이 아니라 ETF를 볼까?

### 개별 주식의 문제점
```
❌ 높은 리스크
  • 한 기업의 실적 부진 → 급락
  • CEO 교체, 불미스한 뉴스 → 급락
  • 기업 특정 리스크 회피 불가능

❌ 기술적 분석 어려움
  • 노이즈(잡음)가 많음
  • 특정 기관의 대량 매도/매수로 차트 왜곡
  • 패턴 확인이 명확하지 않음

❌ 리스크 관리 어려움
  • "분산 투자" 하려면 종목 수가 너무 많아야 함
  • 거래량이 적을 수 있음 (급락 시 팔 수 없음)
  • 비용(수수료)이 높음
```

### ETF의 장점
```
✅ 자동 분산 투자
  • 반도체 ETF 1개 = 반도체 기업 30~50개
  • 한 기업의 부진 영향 최소화 (1/50)
  • 섹터 전체의 추세만 집중 가능

✅ 명확한 기술적 분석
  • 노이즈가 적음 (여러 종목 평균)
  • 큰 추세를 명확하게 볼 수 있음
  • 신고가, 매물대, 양봉 패턴이 뚜렷함

✅ 리스크 관리 최적화
  • 거래량이 충분 (언제든 팔 수 있음)
  • 비중 관리가 간단 (1개 ETF = 1개 포지션)
  • 수수료가 저렴

✅ 당신의 투자 전략과 완벽 매칭
  • RS 확인: 섹터 전체 추세를 명확히 볼 수 있음
  • 추세 투자: 노이즈 적은 깔끔한 차트
  • 리스크 관리: 비중 관리가 수월함
```

### 예시로 이해하기

**개별 주식 (삼성전자) vs ETF (반도체 ETF)**:
```
시나리오: 반도체 산업 전체가 강세 상황

개별 주식 (삼성전자):
  • 삼성: 어려운 경영 결정 + 주가 -3%
  • TSMC: 호황 + 주가 +5%
  • 인텔: 신제품 투자 + 주가 +2%
  • 결과: 같은 시장인데 종목 선택에 따라 수익/손실 극단적으로 다름 ❌

반도체 ETF:
  • 삼성 (-3%), TSMC (+5%), 인텔 (+2%) 모두 포함
  • 평균: 약 +1.5% (산업 추세 반영) ✅
  • 개별 기업 리스크 자동 분산
  • "반도체가 강하다"는 추세에만 집중 가능
```

### 결론
```
개별 주식: 회사 분석가가 되어야 함 (어려움)
ETF: 시장/섹터 트렌드만 추종 (쉬움)

당신의 전략:
  RS + 추세 + 리스크 관리
  → ETF가 최적의 도구 ✅
```

## 1️⃣ WHAT: 무엇을 살 것인가? (가치투자)

### 종목 선정 기준

#### RS (상대강도)
**정의**: RS = 특정 ETF의 일일 수익률 - KOSPI 일일 수익률

**계산 예시**:
```
약세장에서 RS 강함:
  KOSPI: -0.5% (약세)
  반도체 ETF: +1.2% (상승)
  RS = +1.2% - (-0.5%) = +1.7% ✅ (강함)

강세장에서 RS 약함:
  KOSPI: +1.5% (강세)
  반도체 ETF: +0.8% (상승)
  RS = +0.8% - (+1.5%) = -0.7% ❌ (약함)
```

**StockEasy 활용** (섹터분류가 가장 정확):
1. **섹터별 분류** - 추천 ⭐
   - 링크: https://stockeasy.intellio.kr/etf/sector
   - 각 섹터의 일일 수익률 직접 확인
   - 페이지 상단에 모든 섹터의 수익률이 보임
   - KOSPI와 비교해서 RS 계산
   
2. **오늘의 ETF** - 보조용
   - 링크: https://stockeasy.intellio.kr/etf
   - 상승 중인 ETF를 빠르게 훑기 (시간 부족할 때)
   - "상승률" 컬럼으로 정렬
   - 하지만 개별 ETF만 있어서 비교가 어려움

**실제 확인 방법** (섹터분류 페이지):
```
페이지 접속:
  https://stockeasy.intellio.kr/etf/sector

보이는 정보:
  KOSPI 일일 수익률: -0.5%
  반도체: +1.5%        → RS = +2.0% ✅
  전자: +1.2%          → RS = +1.7% ✅
  금융: -1.2%          → RS = -0.7% ❌
  에너지: +0.8%        → RS = +1.3% ✅
  
강한 섹터: 반도체, 전자, 에너지
약한 섹터: 금융

→ 반도체/전자 ETF 중에서 선택
```

#### 펀더멘탈
**정의**: 기업/섹터의 기본이 건전한가?
- 성장성: 매출/순이익 증가 추세
- 수요: 업계 수요가 증가하는가?
- 발류: 역사적 최고가 근처인가?
- 경쟁력: 경쟁사 대비 우위가 있는가?

**StockEasy 활용**:
1. **섹터별 분류** 페이지
   - 링크: https://stockeasy.intellio.kr/etf/sector
   - 각 섹터의 설명 읽기 (성장성 평가)
   - 최근 3개월, 6개월, 1년 수익률 비교
   
2. **ETF 검색** 상세 정보
   - 링크: https://stockeasy.intellio.kr/etf/search
   - 원하는 ETF 검색 후 "구성 기업" 확인
   - 하위 기업들의 성장률 확인
   
3. **시장분석** 섹션
   - 링크: https://stockeasy.intellio.kr/analysis
   - 업종별 뉴스 & 트렌드 파악
   - "반도체 수요 증가", "AI 부흥" 등 확인

**체크 방법**:
```
반도체 섹터 예:
- AI 확산으로 수요 증가? ✅
- 주요 기업(NVDA, TSMC) 매출↑? ✅
- 발류가 역사적 최고가? ⚠️ (주의)
- 신제품으로 경쟁력 강화? ✅

→ 펀더멘탈 양호 ✅
```

```

## 2️⃣ WHEN: 언제 살 것인가? (추세투자)

### 진입 트리거 (기술적 신호)

#### 신고가 돌파
**정의**: 과거 최고가를 뚫고 올라가는 신호
- 가장 단순하고 명확한 신호
- 심리적 저항 선을 뚫음 = 강한 의지 표현

**StockEasy 활용**:
1. **오늘의 ETF** - 신고가 표시 확인
   - 링크: https://stockeasy.intellio.kr/etf
   - "신고가" 배지 찾기
   
2. **ETF 검색** - 개별 차트 확인
   - 링크: https://stockeasy.intellio.kr/etf/search
   - 목표 ETF 검색
   - "차트" 탭에서 봉 형태 보기
   - 최근 봉이 과거 고점 위에 있는가?

3. **스탁이지 AI** - 신호 자동 감지
   - 링크: https://stockeasy.intellio.kr/ai
   - "신고가" 관련 신호 확인
   - AI가 자동으로 신고가 거래량 분석

**체크 방법**:
```
예) 반도체 ETF 최근 52주 최고가: 450,000원
    오늘 종가: 455,000원 → 신고가 갱신 ✅
    
차트 상으로 우상향 추세선 위에 있는가?
```

---

#### 매물대 돌파 (핵심)
**정의**: 조정 구간의 저항선을 뚫고 올라가는 신호

```
패턴:
상승 추세 (1단계)
  ↓
조정 구간 형성 (2단계) ← 매물대 생성
  ↓
장대양봉으로 돌파 (3단계) ← 진입 신호 ✅
```

**왜 차트를 봐야 할까?**
```
WHAT 단계에서 선택한 것:
  "반도체 ETF가 강하다" (RS 강함)
  
WHEN 단계에서 확인할 것:
  "반도체 ETF가 지금 사기 좋은 시점인가?"
  
예시:
  반도체 ETF (RS 강함) 3개 선택:
  ├─ 반도체 ETF A: 신고가 근처 (진입 신호 ✅)
  ├─ 반도체 ETF B: 조정 중 (아직 기다리기 ⏳)
  └─ 반도체 ETF C: 이미 상승 끝 (진입 금지 ❌)
  
→ A만 매매, B는 대기, C는 스킵
→ 같은 섹터인데도 차트마다 다름!
```

**StockEasy 활용**:
1. **각 ETF의 상세 차트 보기** (선택한 종목별로)
   - 링크: https://stockeasy.intellio.kr/etf/search
   - 검색창에 "반도체 ETF" 검색
   - 나온 결과에서 원하는 ETF 클릭
   - 해당 ETF의 상세 페이지 열기
   - 그곳의 "차트" 탭에서 분석
   
2. **차트게임** - 패턴 학습
   - 링크: https://stockeasy.intellio.kr/game
   - 매물대 돌파 패턴 연습
   - 실제 차트 패턴과 비교

**체크 방법**:
```
차트에서 다음을 확인:

1단계: 상승 추세
   ├─ 100일선 상향
   ├─ 52주 신고가로 향함
   └─ 거래량 증가

2단계: 조정 구간
   ├─ 횡보 또는 하락
   ├─ 일정 기간 (1주~1개월)
   ├─ 매물대 형성 (거래량 집중)
   └─ 저점 형성

3단계: 돌파
   ├─ 조정 고점 돌파
   ├─ 장대양봉 출현
   ├─ 거래량 급증
   └─ 진입 신호 ✅
```

---

#### 장대양봉
**정의**: 거래량이 많은 큰 양봉
- 신뢰도: 바디(몸통) 크기가 클수록 강함
- 기준: 평균 봉 크기의 2배 이상?
- 거래량: 평균 거래량 대비 1.5배 이상?

**StockEasy 활용**:
1. **ETF 검색** - 차트 상세 보기
   - 링크: https://stockeasy.intellio.kr/etf/search
   - 목표 ETF 차트 열기
   - 거래량 막대 확인 (차트 하단)
   - 최근 봉의 거래량 vs 평균 비교

2. **액티브/패시브 비교** - 거래량 확인
   - 링크: https://stockeasy.intellio.kr/etf/analysis/active
   - 비슷한 ETF 여러 개 비교
   - 각 ETF의 거래량 추이 비교

**체크 방법**:
```
실제 사례:
평균 하루 거래량: 1,000만 주
오늘 거래량: 2,500만 주 → 2.5배 증가 ✅

그리고 그 날의 봉이
평균 대비 2배 이상 크면
→ 장대양봉 확정 ✅

반대로 거래량만 많고
바디가 작으면 × (의미 없음)
```

#### 내 기준에 맞는가?
**정의**: 당신의 투자 스타일과 일치하는가?

```
개인 거래 기준 설정:
• 수익 목표: 5~20% (자신의 목표)
• 손절 기준: -3~5% (자신의 위험도)
• 보유 기간: 1주~1개월 (시간 여유)
• 포지션 비중: 포트의 3~5% (비중관리)
```

**StockEasy 활용**:
1. **전략실** - 다양한 기준 학습
   - 링크: https://stockeasy.intellio.kr/strategies
   - 다른 투자자의 기준 확인
   - 자신에게 맞는 기준 수립

2. **시장분석** - 시장 변동성 확인
   - 링크: https://stockeasy.intellio.kr/analysis
   - 현재 시장 변동성이 크면?
   - 손절 기준을 더 넓게 설정
   - 수익 목표를 더 낮게 설정

**설정 방법**:
```
예시 1: 공격적 투자자
• 수익 목표: 15~20%
• 손절 기준: -5%
• 보유 기간: 1주
• 비중: 포트의 5~10%

예시 2: 보수적 투자자
• 수익 목표: 5~10%
• 손절 기준: -3%
• 보유 기간: 1개월
• 비중: 포트의 2~3%

현재 시장이 변동성 크면?
모든 수치를 보수적으로 조정
```

## 3️⃣ 포지션 관리 (가장 중요!)

### 리스크 관리

```
진입 직후
├─ 손절가 설정: 진입가 대비 -3~5%
├─ 목표가 설정: 진입가 대비 +5~20%
└─ 최대 손실액 결정

운영 중
├─ 손절이 체결되면 즉시 손실 인정
├─ 목표가 도달하면 부분 익절
└─ 추가 신호가 있을 때만 추가 매수
```

### 비중 관리 (핵심)

```
포트폴리오 100% 기준:

❌ 실수
• 좋은 종목 1개에 집중: 의미 없음
• 손실 종목 1개가 50%: 다른 수익 무용지물

✅ 올바른 관리
• 종목당 비중: 3~10% (자신의 성향에 따라)
• 포트 분산: 최소 10~15개 종목
• 손실액 제한: 포트 대비 -1~2% / 거래
```

**예시**:
```
포트 100만원 기준
- 종목당 5만원 (5%)
- 손실 기준: 2,500원 (-5%) → 총 2,500원 손실
- 포트 영향: -0.25%
- 여러 손실이 나도 포트 타격 최소화
```

### Step 3: 리스크 관리 설정 (HOW)
**참고**: 비중관리가 수익을 결정함

```
[ ] 진입가 결정했나?
    └─ 보유가능 자금: 얼마인가?
    └─ 포트 규모: 얼마인가?
    └─ 진입가 = 현재가? 또는 대기?

[ ] 손절가 설정했나? (필수)
    └─ 진입가의 -3~5% 수준
    └─ 예: 진입가 100,000원
    └─ 손절가: 95,000~97,000원
    └─ → 손실액 = 포트의 1% 이상 되면 안 됨

[ ] 목표가 설정했나?
    └─ 진입가의 +5~20% 수준
    └─ 시장 상황에 따라 조정
    └─ 예: 진입가 100,000원
    └─ 목표가 1차: 105,000원 (+ 부분익절 20%)
    └─ 목표가 2차: 112,000원 (+ 부분익절 30%)
    └─ 목표가 3차: 120,000원 (나머지 익절)

[ ] 포지션 비중 결정했나?
    └─ 포트 규모 * 비중% = 투입 자금
    └─ 예: 포트 1,000만원
    └─ 비중 5% → 50만원 투입
    └─ 비중 3% → 30만원 투입
    
    손실 시나리오:
    └─ 손절 -5% 적용
    └─ 50만원 투입 → 2.5만원 손실 (포트 -0.25%)
    └─ 여러 손실이 나도 포트 타격 최소화
```

**리스크 관리 최종 확인**:
```
손실 규모:
  포트 규모 × 비중 × 손절% = 최대 손실액
  
예: 1,000만원 × 5% × -5% = -25,000원 (포트 -0.25%)
    안전함 ✅

반대로:
    1,000만원 × 50% × -5% = -250,000원 (포트 -2.5%)
    위험함 ❌
```

   └─ 한 종목 손실이 포트에 미치는 영향 최소화

5. 반복 & 기록 (개선)
   └─ 매매일지 작성
   └─ 성공/실패 원인 분석
   └─ 기준 지속적으로 개선
```
