# /blog-plan 워크플로우

콩콩이대작전 블로그의 월별 콘텐츠 캘린더를 기획합니다.

## 실행 단계

### 1단계: 기간 설정
`$ARGUMENTS`에서 연월(YYYY-MM) 파싱합니다.
- 입력이 없으면 현재 날짜 기준으로 다음 달 자동 설정

### 2단계: 캘린더 기획
`blog-planner` 에이전트를 호출하여 월별 콘텐츠 계획을 수립합니다:
- 해당 월의 계절감, 이벤트, 트렌드 반영
- 일상 50% / 맛집·카페 30% / 여행 20% 비율로 구성
- 8~12개 포스팅 주제 생성
- 각 포스팅의 SEO 키워드와 추천 태그 제시

### 3단계: 파일 저장
캘린더를 `blog/plans/YYYY-MM-content-calendar.md`로 저장합니다.

### 4단계: 요약 출력 및 다음 행동 안내
- 이달의 키워드와 포스팅 계획 요약 출력
- 첫 번째 포스팅 작성 제안
- `/blog-post [주제]`로 바로 시작할 수 있도록 안내

---

## 사용 예시

```
/blog-plan 2026-04
/blog-plan 2026-05
/blog-plan              # 다음 달 자동 설정
```

## 저장 위치

캘린더는 아래 경로에 저장됩니다:
```
blog/plans/YYYY-MM-content-calendar.md
```
