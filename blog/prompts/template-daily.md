# 일상 포스팅 템플릿

콩콩이대작전 블로그의 일상/라이프스타일 포스팅 작성 시 참고하는 구조 템플릿입니다.

---

## 제목 패턴

- `[오늘의 키워드]한 하루 💫`
- `요즘 나의 일상 🌿`
- `[계절/날씨]에 어울리는 [활동] ☀️`
- `소소하지만 행복했던 [날짜/요일] 이야기`

예시:
- "봄바람 맞으며 산책한 하루 🌸"
- "비 오는 날 집에서 보내는 법 ☔"
- "요즘 나의 아침 루틴 🌿"

---

## 본문 구조

### 1단락: 오늘의 분위기 도입 (2~3문장)
- 날씨, 기분, 계절감으로 시작
- 독자도 공감할 수 있는 보편적인 감정으로 열기

```
예시:
"요즘 들어 부쩍 봄이 느껴지더라고요 🌸
아침에 일어나서 창문 열었더니 살랑살랑 바람이 들어와서
오늘은 뭔가 좋은 일이 생길 것 같은 느낌이랄까요 😊"
```

### 2~4단락: 오늘의 사건/경험 묘사
- 하루 중 기억에 남는 순간 2~3가지
- 각 순간을 감각적으로 묘사 (보고, 듣고, 맡고, 먹고)
- 사진이 있다면 그 장면을 묘사하는 문장 포함

```
예시:
"오후에는 오랜만에 동네 산책을 나갔어요.
집 근처 공원 벚꽃이 진짜 터질 것 같더라고요 ✨
사람들이 다 나와서 사진 찍고 있는데,
저도 모르게 같이 카메라 꺼냈어요 📸"
```

### 5단락: 마음속 생각/감상
- 경험에서 느낀 소소한 감동이나 깨달음
- 과장 없이 진솔하게

```
예시:
"별것 아닌 것 같은 하루인데,
이런 날이 쌓여서 좋은 추억이 되는 것 같아요.
요즘 바쁘게 지내다 보니 이런 여유가 더 소중하게 느껴지더라고요 🌿"
```

### 마무리: 독자와의 공감 마무리 (1~2문장)
- 독자에게 질문하거나 공감 유도
- 가볍게 끝내기

```
예시:
"여러분의 요즘은 어떠세요? 🤍
저처럼 소소한 일상 속에서 작은 행복 찾고 계신가요?"
```
