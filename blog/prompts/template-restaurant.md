# 맛집/카페 리뷰 포스팅 템플릿

콩콩이대작전 블로그의 맛집/카페 방문기 포스팅 작성 시 참고하는 구조 템플릿입니다.

---

## 제목 패턴

### 맛집
- `[지역] [음식종류] 맛집 | [포인트 한 줄]`
- `[음식명] 진심으로 맛있던 [지역] 맛집 🍜`
- `[지역] 데이트 코스 | 분위기 좋은 [음식종류] 맛집`

예시:
- "연남동 파스타 맛집 | 분위기까지 완벽한 곳 발견 🍝"
- "광장시장 먹방 투어 | 진짜 먹어본 후기 🥟"

### 카페
- `[지역] 감성 카페 | [포인트 한 줄]`
- `[특징] 카페 | [지역] 숨은 감성 카페 찾았다 ☕`
- `[지역] 카페 투어 | [날짜/계절]에 다녀왔어요`

예시:
- "성수동 감성 카페 | 사진 찍기 너무 좋은 곳 ☕"
- "망원동 조용한 카페에서 보낸 오후 🌿"

---

## 본문 구조

### 1단락: 방문 계기 (2~3문장)
- 어떻게 알게 됐는지, 왜 가게 됐는지
- 기대감 살짝 표현

```
예시:
"인스타에서 우연히 발견한 파스타집인데,
사진이 너무 예뻐서 저장해뒀다가 드디어 다녀왔어요 🍝
주말 점심이라 줄 설 각오하고 갔는데 다행히 바로 들어갔어요!"
```

### 2단락: 공간 분위기 묘사 (2~4문장)
- 인테리어, 조명, 음악, 전체적 무드
- 감각적으로 묘사 (보고 느낀 것 중심)

```
예시:
"들어서자마자 나무 인테리어에 따뜻한 조명이 반겨줘요 🌿
창가 자리가 특히 예쁜데, 햇살이 들어오는 게 너무 아늑해서
오래 있고 싶은 그런 공간이었어요.
bgm도 잔잔한 재즈라 대화하기 딱 좋았어요 ☕"
```

### 3~4단락: 메뉴 묘사 (메인 메뉴 1~3가지)
- 외관 묘사 → 맛 묘사 순서
- 먹었을 때의 감각적 경험 중심
- 추천 메뉴 표시

```
예시:
"시그니처 까르보나라를 시켰는데, 비주얼부터 남달랐어요 ✨
면이 진짜 탱글탱글하고 소스가 진하면서도 느끼하지 않은 게
제 입맛에 딱이더라고요!
파스타 먹다가 이렇게 감탄한 건 오랜만인 것 같아요 😋"
```

### 5단락: 실용 정보 (간략하게)
- 가격대 (정확한 가격보다 "비교적 합리적" 등 표현 권장)
- 위치/접근성
- 웨이팅 여부
- 주차 (필요한 경우)

```
예시:
"가격은 메인 메뉴 기준 1만5천~2만원대인데,
양도 푸짐하고 맛 생각하면 충분히 가성비 있는 것 같아요.
홍대역에서 걸어서 10분 정도라 접근성도 좋아요 🚶"
```

### 마무리: 재방문 의향 + 독자 참여
- 솔직한 총평 한 줄
- 어떤 분께 추천하는지
- 독자 참여 유도

```
예시:
"분위기 좋은 곳에서 맛있는 파스타 먹고 싶으신 분들께 강추예요 🍝
데이트 코스로도 딱이고, 혼밥하기도 편한 분위기였어요.
저는 다음에 또 갈 것 같아요! 여러분도 연남동 가시면 꼭 들러보세요 ☺️"
```
