# 여행기 포스팅 템플릿

콩콩이대작전 블로그의 여행/여행기 포스팅 작성 시 참고하는 구조 템플릿입니다.

---

## 제목 패턴

- `[목적지] [기간] 여행기 🗺️`
- `[목적지] 여행 | [핵심 키워드] 총정리`
- `[목적지]에서 보낸 [계절] ✈️`
- `처음 가본 [목적지], 솔직한 후기`

예시:
- "제주도 2박 3일 여행기 | 숨은 명소부터 맛집까지 🍊"
- "봄에 가기 좋은 경주 여행 🌸"
- "혼자 떠난 강릉 당일치기 ✈️"

---

## 본문 구조

### 1단락: 여행 동기/설렘 (2~3문장)
- 왜 이 곳을 선택했는지
- 출발 전 설렘, 기대감 표현

```
예시:
"갑자기 어디론가 훌쩍 떠나고 싶은 마음이 들더라고요 ✈️
마침 연휴가 생겨서 오래 가보고 싶었던 제주도를 드디어 가게 됐어요!
설레는 마음으로 짐을 쌌던 그날이 생각나네요 🧳"
```

### 2단락: 이동/숙소 (1~2단락)
- 이동 수단, 숙소 분위기 간략히
- 실용 정보 (숙소명, 위치) 자연스럽게 포함

```
예시:
"숙소는 제주 시내에서 조금 떨어진 조용한 게스트하우스를 예약했어요.
체크인하자마자 바다가 보이는 창문이 있어서 감탄했다는...! 🌊
가격 대비 정말 만족스러웠어요."
```

### 3~5단락: 주요 장소 (섹션별)
- 방문한 곳 2~3개를 각각 단락으로
- 장소명 + 분위기 묘사 + 느낀 점
- 사진 묘사 문장 포함

```
예시:
"첫 번째로 간 곳은 성산일출봉이었어요 🌅
이른 아침에 올라갔더니 안개가 살짝 끼어 있어서
뭔가 신비로운 분위기였달까요? 숨이 조금 찼지만 꼭대기에서 보는 뷰는 진짜 worth it이에요 👍"
```

### 6단락: 맛있던 것
- 여행 중 먹은 인상적인 음식 1~2가지
- 맛 묘사 상세하게

```
예시:
"점심은 현지 분들이 자주 가신다는 흑돼지 맛집을 찾았어요 🍖
숯불 향이 살살 나면서 고기가 얼마나 부드럽던지...
제주 와서 흑돼지 안 먹으면 섭섭하죠!"
```

### 마무리: 전체 소감 + 팁 + 독자 참여
- 여행 전체 소감 한 줄
- 도움이 될 팁 1~2개 (선택)
- 독자에게 질문

```
예시:
"짧은 여행이었지만 일상 충전 200%는 한 것 같아요 💚
혹시 제주도 가시는 분들은 렌터카 꼭 빌리시길 추천드려요.
대중교통으로는 숨은 명소 찾기가 좀 어렵더라고요 🚗

다음에는 어디로 떠나볼까 고민 중인데,
여러분은 요즘 어디 여행 생각하고 계세요? ✈️"
```
