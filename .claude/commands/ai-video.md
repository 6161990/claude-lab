# /ai-video 워크플로우

AI 영상 제작에 필요한 기획안, 장면별 프롬프트, Hylo 이미지 시안 지시문, Veo 3.1 I2V 프롬프트, 오디오 지시문, 최종 편집 QA 체크리스트를 생성합니다.

## 기본 입력

`$ARGUMENTS`에서 아래 정보를 파악합니다.

- 영상 주제
- 참고 영상 링크 또는 설명
- 목표 플랫폼: 기본 YouTube Shorts
- 영상 길이: 기본 30~60초
- 화면비: 기본 9:16
- 캐릭터 설정
- 원하는 분위기
- 사용 도구: 기본 Hylo, Veo 3.1, Nano-Banana Pro, GPT-1.5 이미지 모델, Hylo Agent

부족한 정보는 합리적으로 가정하고 산출물 상단에 명시합니다.

## 실행 단계

### 1단계: 총괄 제작 브리프

`ai-video-orchestrator` 에이전트를 호출하여 전체 파이프라인과 승인 게이트를 정의합니다.

산출물:
- 제작 브리프
- 고정 스타일 가이드 초안
- 단계별 에이전트 호출 순서
- Hylo 실행용 마스터 지시문

### 2단계: 레퍼런스 분석

참고 영상 링크/설명이 있으면 `video-reference-analyst` 에이전트를 호출합니다.

산출물:
- 후킹 구조
- 컷 구성 패턴
- 시각 스타일
- 새 주제 변환 방향

### 3단계: 장면별 프롬프트

`video-scene-prompt-director` 에이전트를 호출합니다.

산출물:
- 고정 캐릭터/스타일 가이드
- 공통 부정 프롬프트
- 장면별 이미지 생성 프롬프트
- 장면별 영상 생성 프롬프트 초안

### 4단계: Hylo 이미지 시안 지시문

`hylo-image-board-agent` 에이전트를 호출합니다.

중요:
- 바로 영상을 만들지 않습니다.
- Nano-Banana Pro 기준으로 장면당 4컷 이미지 시안만 요청합니다.
- 선택/리젝 기준을 함께 출력합니다.

### 5단계: I2V 영상화 지시문

사용자가 선택한 이미지가 있거나 선택 기준까지 정리되면 `hylo-i2v-director` 에이전트를 호출합니다.

산출물:
- Veo 3.1 I2V 장면별 프롬프트
- GPT-1.5 이미지 모델 수정 지시문
- 컷 연결 메모

### 6단계: 오디오 지시문

`video-audio-director` 에이전트를 호출합니다.

산출물:
- BGM 생성 프롬프트
- 나레이션 보이스 가이드
- 장면별 나레이션 대본
- 효과음 큐시트
- 믹싱 가이드

### 7단계: 최종 편집 QA

`video-editing-qa-reviewer` 에이전트를 호출합니다.

산출물:
- 컷별 검수표
- 캐릭터 일관성 체크
- 오디오/자막 싱크 체크
- 재생성 지시문
- 최종 편집 체크리스트
