# /blog-post 워크플로우

콩콩이대작전 블로그에 소재와 사진만 주면 알아서 포스팅합니다.

## 사진 디렉토리
사진 파일은 `/Users/j6161990/Documents/GitHub/claude-lab/blog/photo/` 에 두세요.
파일명만 알려주시면 절대경로로 자동 변환합니다.

## 카테고리
소재를 보고 아래 4개 중 자동 선택:
- **일상**: 일상, 산책, 피크닉, 소소한 이야기
- **카페**: 카페 방문, 음료, 베이커리
- **맛집**: 음식점, 식당, 맛집 리뷰
- **여행**: 국내외 여행, 나들이

---

## 실행 단계

### 1단계: 입력 파싱
`$ARGUMENTS`에서 아래 두 가지를 분리합니다:
- **소재**: 포스팅 주제, 경험, 메모
- **사진**: `사진:` 키워드 뒤에 오는 파일명 목록 (없으면 텍스트만 발행)

```
예시 입력:
"오늘 삼각지 에피하우스 카페 다녀왔어. 사진: cafe1.jpg, cafe2.jpg"
```

### 2단계: 장소 정보 검색 (카페/맛집인 경우)
소재에서 장소명이 파악되면 WebSearch로 아래 정보를 수집합니다:
- 정확한 주소
- 영업시간
- 주차 가능 여부
- **화장실 유무**
- **와이파이 제공 여부**
- 전화번호
- 기타 특이사항 (콘센트, 반려동물 동반 등)

검색 쿼리 예시: `"[장소명] 화장실 와이파이 영업시간 주소"`

### 3단계: 글 작성
`blog-writer` 에이전트를 호출하여 콩콩 스타일 초안 생성.

- 2단계에서 수집한 장소 정보를 정보 블록에 포함:
  ```
  📍 장소 : [주소]
  ⏰ 영업시간 : [시간]
  🚗 주차 : [정보]
  🚻 화장실 : [있음/없음/미확인]
  📶 와이파이 : [있음/없음/미확인]
  ☎️ 전화번호 : [번호 또는 미확인]
  ```
- 사진이 있는 경우 본문에 `[사진1]`, `[사진2]` 등 **사진 삽입 위치 마커** 포함
- `blog/prompts/meta-prompt.md` 문체 규칙 적용

### 4단계: 글쓰기 페이지 이동
```
https://blog.naver.com/PostWriteForm.naver?blogId=kong__home
```
로그인이 필요하면 `https://nid.naver.com/nidlogin.login?mode=form` 으로 이동 후:
- JS evaluate로 ID/PW 입력 후 로그인 버튼 클릭
- `.env` 파일의 `NAVER_ID`, `NAVER_PASSWORD` 사용

### 5단계: 제목 입력
1. 제목 영역 클릭 (paragraph "제목" ref)
2. 클립보드(navigator.clipboard.writeText)로 제목 복사 후 Meta+v 붙여넣기

### 6단계: 본문 및 사진 삽입
사진 없는 경우:
- 본문 영역 클릭 후 클립보드 붙여넣기

사진 있는 경우 (마커 위치에 사진 삽입):
1. 본문을 `[사진N]` 마커 기준으로 분할
2. 각 텍스트 블록 입력 후 사진 삽입 반복:
   ```
   텍스트 블록 입력
   → "사진 추가" 버튼 클릭 (툴바의 사진 아이콘, ref로 찾기)
   → file chooser 트리거 대기
   → mcp__playwright__browser_file_upload로 절대경로 전달
   → 업로드 완료 대기
   → 다음 텍스트 블록 입력
   ```

### 7단계: 장소 카드 삽입 (카페/맛집인 경우)
본문 입력 완료 후, 정보 블록 위치에 네이버 지도 카드를 추가합니다:
1. 정보 블록 텍스트 아래 커서 이동
2. 툴바에서 "장소 추가" 버튼 클릭 (snapshot으로 ref 확인)
3. 장소 검색창에 장소명 입력
4. 검색 결과에서 해당 장소 선택 → 본문에 지도 카드 삽입
5. 장소 카드가 삽입되면 텍스트 정보 블록은 그대로 유지 (둘 다 있으면 더 좋음)

### 8단계: 카테고리 · 태그 · 발행
1. "발행" 버튼 클릭 → 발행 설정 패널 오픈
2. 카테고리 드롭다운에서 소재에 맞는 카테고리 선택 (일상 / 카페 / 맛집 / 여행)
3. 태그 입력창에 추천 태그 순서대로 입력 (Enter로 구분)
4. 최종 "발행" 버튼 클릭
5. 발행 완료 후 포스팅 URL 안내

### 9단계: 관련 포스팅 좋아요 · 이웃신청
발행 완료 직후 포스팅의 태그 키워드로 네이버 블로그를 검색하여 커뮤니티 활동을 합니다.

#### 좋아요 (10개)
1. 대표 태그 1~2개로 네이버 블로그 검색:
   ```
   https://search.naver.com/search.naver?where=blog&query=[태그키워드]
   ```
2. 검색 결과에서 **kong__home이 아닌** 타 블로거 포스팅 10개 순회
3. 각 포스팅에서 좋아요(하트) 버튼 클릭
   - 좋아요 버튼 ref: snapshot으로 확인 (보통 `공감` 또는 하트 아이콘)
   - 클릭 간 랜덤 딜레이 1~3초 적용
4. 좋아요 완료한 포스팅 목록 기록

#### 이웃신청 (5명)
1. 좋아요한 10명 중 앞에서 5명의 블로그 방문
2. 각 블로그에서 이웃신청 버튼 클릭:
   - 블로거 프로필 영역의 "이웃추가" 또는 "서로이웃 신청" 버튼
   - snapshot으로 ref 확인 후 클릭
   - 이웃신청 확인 팝업 → 확인 버튼 클릭
   - 클릭 간 랜덤 딜레이 2~4초 적용
3. 이웃신청 완료한 블로거 목록 기록

#### 완료 리포트
```
✅ 발행 완료: [포스팅 URL]

👍 좋아요 (10개):
- [블로거1] 포스팅 제목
- [블로거2] 포스팅 제목
...

🤝 이웃신청 (5명):
- [블로거1]
- [블로거2]
...
```

## 사용 예시

```
# 텍스트만
/blog-post 오늘 한강 피크닉 다녀온 이야기

# 사진 포함
/blog-post 연남동 감성 카페 발견했어! 라떼 비주얼 미쳤음. 사진: cafe1.jpg, cafe2.jpg

# 여행기 + 사진 여러 장
/blog-post 제주도 2박3일. 성산일출봉, 우도, 흑돼지 먹음. 사진: jeju1.jpg, jeju2.jpg, jeju3.jpg, jeju4.jpg

# 맛집 리뷰
/blog-post 홍대 파스타 맛집. 까르보나라 진짜 맛있었고 분위기도 좋음. 사진: pasta1.jpg, pasta2.jpg
```

## 에러 처리
- 로그인 세션 만료 → 자동 재로그인
- 사진 파일 없음 → 해당 파일 건너뛰고 계속 진행 후 사용자에게 알림
- 업로드 실패 → 재시도 1회 후 텍스트만 발행
- 장소 검색 결과 없음 → 텍스트 정보 블록만 사용, 지도 카드 생략
- 장소 정보 검색 불가 → 해당 항목 "미확인"으로 표기
- 좋아요 버튼 없음 (비공개 포스팅 등) → 해당 포스팅 건너뛰고 다음으로
- 이미 이웃인 블로거 → 건너뛰고 다음 블로거로
- 이웃신청 팝업 구조 변경 → snapshot으로 재확인 후 재시도
