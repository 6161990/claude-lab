# 한국 주식 고거래대금 스크리너 MVP PRD

## 핵심 정보

**목적**: 한국 주식 시장에서 최근 2개월간 거래대금 1000억 원 이상 종목을 빠르게 스크리닝하여 투자자가 시장 주도 종목을 한눈에 파악할 수 있게 한다.

**사용자**: 한국 주식 시장을 직접 분석하는 개인 투자자 및 주식 트레이더

---

## 사용자 여정

```
1. 홈 페이지 (스크리너 메인)
   - 서비스 최초 진입 시 로그인 없이 바로 스크리너 화면 노출
   ↓ 기간 및 거래대금 필터 설정 후 [조회] 버튼 클릭

2. 데이터 로딩 상태
   - KRX/외부 API에서 데이터 수집 중 로딩 스피너 표시
   ↓ 데이터 수집 완료

   [수집 성공] → 종목 목록 페이지로 자동 이동
   [수집 실패] → 오류 메시지 표시 후 홈 페이지 재시도 유도
   ↓

3. 종목 목록 페이지
   - 조건을 만족하는 종목 목록 테이블 형태로 표시
   ↓ 특정 종목 행 클릭

4. 종목 상세 페이지
   - 해당 종목의 기간별 거래대금 추이 및 상세 데이터 표시
   ↓ 뒤로 가기 또는 목록으로 돌아가기 클릭

5. 종목 목록 페이지 복귀 → 다른 종목 탐색 또는 필터 재조정
```

## 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|--------------|------------|
| **F001** | 거래대금 스크리닝 | 최근 2개월 기간 내 하루라도 거래대금 1000억 원 이상을 기록한 종목 필터링 | 서비스의 핵심 가치 제공 | 홈 페이지, 종목 목록 페이지 |
| **F002** | 종목 목록 조회 | 조건을 만족하는 종목을 테이블 형태로 표시 (종목명, 코드, 최대 거래대금, 발생 일수, 시장 구분) | 사용자가 결과를 탐색하기 위한 핵심 기능 | 종목 목록 페이지 |
| **F003** | 기간별 거래대금 추이 조회 | 선택된 종목의 최근 2개월 일별 거래대금 차트 및 상세 데이터 표시 | 투자자가 종목의 수급 패턴을 파악하기 위한 필수 기능 | 종목 상세 페이지 |
| **F004** | 시장 구분 필터 | KOSPI, KOSDAQ, 전체 중 선택하여 조회 범위 설정 | 투자자가 관심 시장에 집중할 수 있게 하는 기본 필터 | 홈 페이지, 종목 목록 페이지 |
| **F005** | 목록 정렬 | 최대 거래대금, 거래대금 발생 일수, 종목명 기준 오름차순/내림차순 정렬 | 사용자가 원하는 기준으로 종목을 탐색하기 위한 필수 기능 | 종목 목록 페이지 |
| **F006** | KRX 공공데이터 수집 | KRX 정보데이터시스템 또는 FinanceDataReader를 통해 일별 거래대금 데이터 수집 | 신뢰할 수 있는 공식 데이터 소스 활용 | 데이터 수집 처리 (백엔드) |

| 필드 | 설명 | 타입/관계 |

| date | 거래일 (영업일) | Date |
| trading_value | 거래대금 (원 단위) | BigInteger |
| trading_volume | 거래량 (주 단위) | BigInteger |
| close_price | 종가 (원 단위) | Integer |

### Favorite (즐겨찾기)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |

## 기술 스택 (최신 버전)

### 프론트엔드 프레임워크

- **Next.js 15** (App Router) - React 풀스택 프레임워크, 서버 컴포넌트로 초기 데이터 로딩
- **TypeScript 5.6+** - 타입 안전성 보장
- **React 19** - UI 라이브러리 (최신 동시성 기능)

### 스타일링 & UI

- **TailwindCSS v4** (설정파일 없는 새로운 엔진) - 유틸리티 CSS 프레임워크
- **shadcn/ui** - 테이블, 버튼, 폼 등 고품질 React 컴포넌트
- **Lucide React** - 아이콘 라이브러리
