# 콩콩이대작전 네이버 블로그 디자인 개선 가이드

현재 블로그는 다크 사이드바 테마입니다.
밝고 감성적인 톤으로 개선하기 위한 단계별 설정 가이드입니다.

> 네이버 블로그 디자인은 API가 없어 블로그 관리자 페이지에서 직접 설정해야 합니다.
> 이 가이드를 보면서 순서대로 진행해주세요.

---

## 1. 블로그 정체성

| 항목 | 내용 |
|------|------|
| 블로그명 | 콩콩이대작전 |
| 컨셉 | 일상의 소소한 행복을 기록하는 감성 공간 |
| 키워드 | 밝음, 따뜻함, 봄 느낌, 파스텔, 개인적 |
| 주제 | 일상 / 여행 / 맛집·카페 |

---

## 2. 스킨 선택 가이드

**설정 경로**: 블로그 관리 → 꾸미기 설정 → 레이아웃·위젯 설정 → 스킨 변경

### 추천 스킨 조건
- ✅ 흰색/크림 배경
- ✅ 넓은 여백, 깔끔한 레이아웃
- ✅ 2단 레이아웃 (본문 넓게)
- ✅ 심플하고 텍스트 가독성 높은 디자인

### 추천 스킨 키워드
- "심플" 계열: Simple White, 깔끔한 흰색 배경
- "봄/꽃" 계열: 봄날, 플라워, 핑크
- "감성" 계열: 미니멀, 노트, 다이어리

> 네이버 스킨 목록은 자주 변경되므로, 위 조건에 맞는 스킨을 직접 미리보기로 확인해주세요.

---

## 3. 컬러 팔레트 (밝고 파스텔 감성)

현재 다크 테마에서 아래 컬러로 변경을 권장합니다.

| 역할 | 색상명 | HEX 코드 |
|------|--------|----------|
| 메인 포인트 | 피치 핑크 | `#FFB5A7` |
| 서브 포인트 | 민트 그린 | `#B5EAD7` |
| 배경 | 크림 화이트 | `#FFF9F5` |
| 텍스트 | 소프트 차콜 | `#4A4A4A` |
| 링크/강조 | 로즈 핑크 | `#E8929A` |

**설정 경로**: 블로그 관리 → 꾸미기 설정 → 세부 디자인 설정

---

## 4. 카테고리 구조

**설정 경로**: 블로그 관리 → 메뉴·글·동영상 관리 → 카테고리 관리

아래 카테고리 구조로 설정하세요:

```
🌸 일상이야기          (일상 포스팅)
✈️ 여행일기            (여행 포스팅)
   └ 국내여행
   └ 해외여행
🍜 맛집탐방            (음식점 리뷰)
   └ 서울
   └ 경기·인천
   └ 지방·제주
☕ 카페투어            (카페 방문기)
```

> 이모지는 카테고리 이름 앞에 직접 입력하면 됩니다.

## 5. 프로필 설정

**설정 경로**: 블로그 관리 → 기본 설정 → 블로그 정보

### 블로그 이름
```
콩콩이대작전
```

### 별명
```
콩콩
```

### 블로그 소개글 (추천 문구)
```
일상의 작은 행복을 기록하는 콩콩이에요 🌱
맛있는 것 먹고, 예쁜 곳 가고, 소소한 하루하루를 담아요 ✨
```

### 프로필 이미지 방향
- 얼굴 사진 또는 감성 소품 사진 (꽃, 커피잔, 여행지 등)
- 밝고 자연스러운 빛이 있는 사진
- 정사각형 크기로 준비 (권장: 200×200px 이상)

---

## 6. 커버/대표 이미지 방향

**설정 경로**: 블로그 관리 → 꾸미기 설정 → 타이틀 이미지

### 이미지 스타일
- 플랫 레이(flat lay): 책상 위 소품, 커피잔, 꽃 등 위에서 찍은 사진
- 자연광이 들어오는 카페/창가 감성 사진
- 봄/여름 느낌의 밝은 풍경 사진

### 컬러 톤
- 전체적으로 밝고 따뜻한 자연광 느낌
- 파스텔 계열 (핑크, 민트, 크림, 라벤더)
- 채도를 약간 낮춰 자연스러운 무드

### 무료 제작 도구
- **Canva** (canva.com): 블로그 배너 템플릿 검색 → 파스텔 계열 선택
  - 추천 키워드: "blog banner pastel", "aesthetic blog header"
- **권장 크기**: 966×130px (네이버 블로그 타이틀 기준)

---

## 7. 포스팅 이미지 편집 가이드

포스팅에 올리는 사진을 일관된 감성으로 편집하면 블로그 전체 무드가 통일됩니다.

### 기본 보정 방향
- 밝기: +10~20% 높이기 (전체적으로 밝게)
- 대비: 살짝 낮추기 (부드러운 느낌)
- 채도: -5~10% 낮추기 (자연스러운 파스텔 톤)
- 색온도: 따뜻하게 (약간 노란빛)

### 추천 앱
- **VSCO**: A4, A6 필터 (밝고 따뜻한 톤)
- **Lightroom Mobile**: 무료 프리셋 "Warm Bright" 계열
- **스냅시드**: 기본 보정으로 충분

### 텍스트 오버레이 폰트
- 나눔손글씨 계열 (네이버 폰트, 무료)
- 감성적인 한글 손글씨 느낌
